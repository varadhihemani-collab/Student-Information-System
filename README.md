# 🎓 Student Information System

A responsive web-based Student Information System developed for the Data Alcott Systems Web Development Internship Task.

## 📌 Project Overview

The Student Information System is designed to manage student information and academic records through a simple, clean and responsive web interface.

The project allows users to register students, view student profiles, manage academic records, attendance and fees, generate student ID cards, and generate reports.

## ✨ Features

### 📊 Dashboard
- Total students
- Active students
- Number of departments
- Attendance percentage
- Average GPA / CGPA
- Enrollment overview

### 👨‍🎓 Student Management
- Student registration
- Multi-step registration form
- Student listing
- Search students
- Filter by department
- Filter by year
- Filter by status
- View student profile
- Edit student details
- Delete student details

### 📚 Academic Records
- Select a student
- Add subject records
- Add marks
- Add credits
- View academic records

### 📅 Attendance
- Select a student
- Add attendance by date
- Mark Present / Absent
- Calculate attendance percentage

### 💰 Fee Management
- Select a student
- Add total fee
- Add paid fee
- Manage fee status
- View fee records

### 📁 Student Documents
- Select student
- Select document
- Manage student documents

### 🪪 Student ID Card
- Select student
- Generate student ID card

### 📊 Reports
- Generate student reports
- Export student data as CSV
- Print reports

### 🔐 Login / Register
- Login form
- User registration
- Basic client-side authentication

### 🌙 Dark Mode
- Light mode
- Dark mode

### 💾 Data Storage
- Student and application data is stored using browser LocalStorage.
- No external database is used in this version.

## 🛠️ Technologies Used

- JavaScript
